**#Card League Baseball Analytics**
An independent baseball analytics and simulation project built using Python and R.

**Project Overview**

Card League Baseball (CLB) is a custom baseball league derived from statistics on baseball trading cards. This project uses Python to simulate games, project team standings, and develop statistical evaluation methods.  It also uses R to visualize and evaluate player and team performance metrics

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- R
Key Features
- Baseball game simulation engine
- Full-season Monte Carlo simulations
- Team win probability projections
- Custom WAR and run expectancy calculations
- Statistical visualizations

Project Goals
Develop practical programming, statistical modeling, and data analytics skills through an independent baseball analytics project.
